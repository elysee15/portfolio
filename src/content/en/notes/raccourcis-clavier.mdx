title: "Keyboard shortcuts"
date: 2026-02-02
tags: ["ux"]
---

What I expect from a site that calls itself well made: that it answers the
keyboard before it answers the mouse.

| Shortcut | Action |
| --- | --- |
| <kbd>⌘K</kbd> | Open the palette |
| <kbd>Esc</kbd> | Close |
| <kbd>/</kbd> | Search |

The palette loads on the first <kbd>⌘K</kbd>, not on page load.
